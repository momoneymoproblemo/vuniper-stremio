What this is

An unofficial, fan-made Stremio add-on. It adds catalog rows only: titles, posters and details, so you can find something to watch. It doesn't host or provide any streams. Every 6 hours it checks Vuniper's lists and saves them here, so installing it adds no extra load on Vuniper however many people use it.

All the curation is thanks to Vuniper, a brilliant site for keeping up with new movie, show and game releases. If you find this useful, go and use the real thing too and show them some love. This project isn't affiliated with or endorsed by Vuniper.
